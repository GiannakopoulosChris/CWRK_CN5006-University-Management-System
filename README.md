# Ολοκληρωμένο Σύστημα Διαχείρισης Πανεπιστημίου (PHP/MySQL)

Αυτή η εφαρμογή αποτελεί το πρωτότυπο ενός συστήματος διαχείρισης μαθημάτων και εργασιών.

## Λειτουργίες
- **Ασφάλεια:** Υλοποίηση Role-Based Access Control (RBAC).
- **Ρόλοι:** Διαφορετικό περιβάλλον για Καθηγητές (διαχείριση μαθημάτων/βαθμολόγηση) και Φοιτητές (προβολή/υποβολή εργασιών).
- **Responsive Design:** Πλήρης συμβατότητα με κινητά και tablet μέσω Bootstrap 5.
- **Interactive Map:** Ενσωμάτωση Leaflet.js για την απεικόνιση του campus.

## Οδηγίες Εγκατάστασης
1. Εισαγωγή της βάσης δεδομένων `university_db.sql`.
2. Ρύθμιση της σύνδεσης στο `prototype/includes/db.php`.
3. Χρήση κωδικών εγγραφής: `STUD2025` / `PROF2025`.
